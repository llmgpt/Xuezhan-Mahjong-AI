# V11：受约束的进攻收入与点炮赔付比较

**实验候选已实现，工程与真实worker接入通过，尚无V11新实战成绩。** 策略ID为`candidate-advanced-liability-v11`；默认页面仍用原老师。本轮使用[公开基础赔付预测原型](PUBLIC_LIABILITY_MODEL.md)已经固定的系数，没有重新训练或按牌局成绩调参。源码、RED→GREEN及工具退出见[实现记录](benchmarks/independent-v11-implementation.json)。

## 实际改动

普通合法点胡沿用V10直接收取当前实收，其余响应、自摸、碰杠和老师开局沿用同一full/ready-income基础。只有基础Python策略实际返回弃牌、本家已经清缺且没有当前合法自摸时，才比较其他合法弃牌。

- 每个替代必须与基础策略的实际弃牌保持相同的合法等待纠正后向听，未见有效进张数量不能减少。正常轮转已无本家摸牌预算时，理论查叫最高牌型分也不能减少。这些是保守代理约束，不保证长远进攻价值不下降。
- 在满足约束的候选中，用至多两次本家正常摸牌的均匀未见牌模型自摸收入，减去本次潜在点炮赔付总额。系数固定为1；差在1e-12内沿用原弃牌，不扫阈值。多于一向听的进攻收入暂记0，只代表此短模型看不到，不能说明那些手牌实际价值相同。
- 每家赔付来自固定的0/1/2/4/8基础分布。当前公开杠后补摸、最后墙加番先逐类别封顶到8，再对多家期望求和；没有把各家事件当独立。清缺、赢家退出和四张全明的单张手等确定零规则仍生效。

这是近摸收入与学习赔付的组合改动；将来的净分变化不能单独归因于风险预测。模型不预测对手是否拒胡，也没有计入完整未来点胡、碰杠、玩家退出和后续收付。旧模拟分布与实际新路径可能不同，低概率过度保守和高风险尾部低估仍保留。

## 记录与复核

每次实际比较保存基础worker真正返回的弃牌、全部结构约束、参与比较的进攻值、每家五类概率、加番后的金额和最终动作。解释直接展示所用数值与局限。观察者收到副本，不能修改实际动作。

评测原始`evaluations`另有`public-liability-discard-v1`类别，不冒用粒子或未来净分样本。审计器在对应的完整公开view上重算固定比较：概率、金额、基准或选择篡改会拒绝，应有附录而遗漏也会拒绝。重算以已记录的真实worker基准为条件，不重新询问外部策略来独立证明每个基准；源码、实际子进程、运行时和完整轨迹身份仍须单独核验。

公开模型只依赖11个本家/规则/计分模块与固定系数文件，浏览器目标构建没有全状态引擎、暗手oracle、私有数据集、文件系统、Python或评测器依赖。它没有接入浏览器UI，依赖检查不等于浏览器实操通过。

## 统计方法

所有差值方向均为 **完整老师减对照**，正数表示完整老师净分更高。对每个种子，先将同座位、同对手的两策略净分相减，再对四座位、两类对手等权平均，得到 200 个种子差值。以它们的样本标准差除以 √200 得标准误 SE，95% 区间采用预定的正态近似：均值 ± 1.96 × SE。

分对手统计只在种子内平均四座位；两类等权的分座位统计只在种子内平均两类对手；单一对手、单一座位也以 200 个种子配对计算。相关的座位和对手没有被当作独立样本。四分片全部纳入，合并时从原始种子重算，未平均分片标准误或区间。独立复算与保存的合并结果一致。报告展示数字四舍五入到小数点后四位；合并 JSON 保留主比较的完整精度，原始 JSONL 可重算本报告所有对照。

### 出牌推荐模块消融的含义

`teacher-legacy-discard` 保留新换牌、定缺及响应窗口逻辑，将出牌推荐模块回退原策略。自杠比较中的“不杠”弃牌基准也来自这个模块，可能随回退改变。因此这项消融包含模块耦合及后续牌局影响，并非严格固定全部非出牌动作后只替换一张弃牌。

回退版相对 `advice` 仍增加 **0.9019 分/局**，SE 0.1164，95% 区间 [0.6738, 1.1300]；相对 `efficiency` 增加 **0.8844 分/局**，SE 0.1148，区间 [0.6593, 1.1094]。这支持本次主要增益来自新换牌与定缺的组合，不能据此将功劳单独归给其中任何一项。

完整老师相对回退版的总体区间 [-0.0961, 0.1286] 跨零：未证明新出牌模块额外提升净分，也不能推断两者相等或任何局面都没有退步。区间下界高于预定容差 -0.25 分／局，因此满足本次总体模块验收条件。

## 复现与结果完整性

使用上述冻结策略源码版本和 Node.js 22，执行 `npm ci` 安装锁定依赖。下面的 PowerShell 示例顺序完成同样的四分片；也可把四组起始种子放在独立进程运行，每个进程使用不同输出文件，并保持源码和其他配置完全相同。

```powershell
npm ci

$benchmarkOutputDir = 'local/benchmarks/reproduce-teacher-v1'
if (Test-Path -LiteralPath $benchmarkOutputDir) {
  throw '请为本次复现选择一个新的输出目录。'
}
New-Item -ItemType Directory -Path $benchmarkOutputDir | Out-Null

$env:EVAL_COUNT = '50'
$env:EVAL_SEATS = '0,1,2,3'
$env:EVAL_POLICIES = 'advice,efficiency,teacher-candidate,teacher-legacy-discard'
$env:EVAL_OPPONENTS = 'greedy,patient'

$benchmarkFiles = @()
foreach ($benchmarkStart in @(70000, 70050, 70100, 70150)) {
  $env:EVAL_START = [string]$benchmarkStart
  $env:EVAL_OUTPUT = Join-Path $benchmarkOutputDir "teacher-v1-shard-$benchmarkStart.jsonl"
  $benchmarkFiles += $env:EVAL_OUTPUT
  npm run evaluate:advice
  if ($LASTEXITCODE -ne 0) {
    throw "分片 $benchmarkStart 未完成；请先处理错误。"
  }
}

npx vite-node scripts/analyze-benchmark.ts @benchmarkFiles
```

分析命令会读取全部原始种子，重算总体、分对手、分座位和老师直接对照的统计；它不运行牌局或改写输入。检查本报告归档数据可直接运行：

```powershell
npx vite-node scripts/analyze-benchmark.ts `
  docs/benchmarks/teacher-v1-shard-70000.jsonl `
  docs/benchmarks/teacher-v1-shard-70050.jsonl `
  docs/benchmarks/teacher-v1-shard-70100.jsonl `
  docs/benchmarks/teacher-v1-shard-70150.jsonl
```

复现时四分片必须全部纳入，不根据中途成绩选择分片、增减样本或调整策略。源文件截断、配对缺失、种子重复、版本不一致或种子不连续时，分析会拒绝汇总。技术中断可以在相同配置与精确源码指纹下继续同一输出文件，只复用已完整保存的种子。

指纹以文件的**精确字节**计算，行结束、编码或任何源码修改也会改变指纹。异平台检出造成字节变化时，应使用新的输出目录重新跑完整配置，保留其新 manifest；不能篡改旧 manifest 以绕过续跑检查或混入本次正式结果。四份归档 JSONL 的 SHA256 与字节数见上表。已看过本次结果后若修改老师，应将这组种子转为开发材料，先登记新的未用留出区段再评估。

## 结论的适用范围

本次比较针对同一 V1 模拟器、两个内部非随机基线及两类冻结电脑对手。它提供可复现的策略收益证据，尚未覆盖人类高手、不同地区规则、其他对手或多人混合策略。模拟器规则与策略估算中的偏差也可能共同影响结果。

没有把内部胜率、简化两摸模型或单局输赢当作教学正确性的证明。数据不证明每手推荐唯一最优，不证明新出牌模块全面改善，也不直接证明玩家通过观看后已经提升牌技。真实牌例检查和用户整局试玩仍用于发现策略、解释及体验问题；下一轮变更须保留这些边界，并重新使用未见留出种子确认收益。

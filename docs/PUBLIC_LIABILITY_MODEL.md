# 公开信息基础点胡赔付预测原型

**旧开发数据上的预测检验通过，尚无新策略实战提升证据。** 原型只预测某张合法弃牌被指定对手合法点胡时的基础赔付分布，没有接入玩家、托管或V10。本轮不是强化学习，也没有高手牌谱标签。数据、固定参数、全部分层和真实执行记录见[机器记录](benchmarks/public-liability-feasibility-20261023.json)。

## 数据和任务

完整重放已结束V9组的1920条T/V8旧轨迹：40个旧seed、四席、三阵容、两种开局、两策略。核207,193状态、124,897决定及7680项共同开局老师动作。对每个实际弃牌节点，枚举不同的合法弃牌与活跃对手，离线用宿主规则给真实暗手计算基础胡值，得到1,069,319次标签、568,162个聚合行。它们仍只有40个原始seed单位，不能当作百万个独立牌局。

标签为0/1/2/4/8：0表示不能合法胡，其他为本V1的基础单家赔付。局部番型上下文为空，未含杠上炮、海底等情景加番，也不预测对手是否选择胡、未来净分或一炮多响后的完整路径。标签与规则检查共享宿主实现，不能独立证明规则本身正确。

32个输入只来自当事玩家手牌、明牌、剩余墙数和公开动作历史。包括对手副露、清缺的公开证据、可见同牌与邻牌、牌序边界；不含真实暗手、暗墙顺序、seed、阵容/策略标识或未来信息。真实暗手只供离线标签函数。已核暗手与暗墙交换后公开view/特征不变而标签改变，核花色轮换、牌序反射、库存及真实宿主点胡收付。曾弃过某牌不能据此判定永远安全。

三种公开规则强制输出零：对手已胡退出、弃牌为对手缺门，或对手只剩一张暗牌且四张目标牌已全部可见。其他推断均保留不确定性。公开库存把被碰杠拿走的弃牌排除，避免重复计数。

## 固定检验与完整结果

计划在提取前固定。每个配置总权重相同，其内按弃牌节点、不同合法候选和活跃对手等分；训练时每seed总质量归一为1。按seed预先分五折，每次32训练、8验证，同seed的全部座位、候选和阵容同时隔离。使用固定多分类逻辑回归，C=100、lbfgs、最多400次、容差1e-8；未调参，五折均无收敛警告。权重、概率类别顺序及分组方法参考[scikit-learn 1.6文档](https://scikit-learn.org/1.6/modules/generated/sklearn.linear_model.LogisticRegression.html)和[分组验证文档](https://scikit-learn.org/1.6/modules/cross_validation.html#cross-validation-iterators-for-grouped-data)。

对照包含训练折内加权常数分布，以及按副露数量×剩余墙区间的公开查表（固定0.1个seed质量向全局收缩）。三者使用相同强制零规则。以下全部是验证折加权误差，越小越好：

| 方法           | 多类对数损失 | 能胡概率Brier误差 | 基础赔付均方误差 |
| -------------- | -----------: | ----------------: | ---------------: |
| 常数分布       |     0.147713 |          0.027252 |         0.189023 |
| 公开分层查表   |     0.133190 |          0.026410 |         0.182169 |
| 32特征逻辑回归 |     0.121506 |          0.025340 |         0.168914 |

相对查表三项误差下降8.77%、4.05%、7.28%。三阵容、两开局、五副露数量和四墙区间的汇总指标都改善；40个seed的对数损失均改善。但60025的Brier变差，60008/60011/60025的赔付均方误差变差，完整正负分层均保留。相互重叠的训练折没有另报名义置信区间。

总体真实能胡比例2.8464%，预测2.8557%；真实平均基础赔付0.055309，预测0.055384。这是每个候选/对手的加权暴露量，不是每局净分。总体接近不能证明每段校准良好：预测低于1%的段实际约0.185%，预测约0.668%，偏保守；预测40%–60%的尾段实际能胡约55.6%、预测44.7%，基础赔付实际3.102、预测1.501，明显低估，且尾段质量很小。

## 推理、复现与边界

最终导出模型拟合全部40旧seed，因此这批旧seed不能再用作该模型未见的实战测试。256个预先均匀选定的样本已核便携TypeScript推理与Python概率，最大差3.33e-16；并核大幅logit下的稳定softmax、强制零、特征次序和非法参数。浏览器推理依赖只有`inference.ts`、`features.ts`和牌工具，没有离线暗手oracle、数据集、文件系统或评测运行时。

特征/标签7组、训练数学5项、推理核对及5个私有TypeScript根文件零诊断均有真实通过记录；实现前保留失败结果。它们是合成规则与数学核对，没有新增强度局。V10策略与运行配置未变，本研究没有读取当前V10对局结果。

私有证据位于`local/strength-goal-20261018/opponent-liability-prototype/`，机器记录绑定21项文件，包括数据SHA、源码、模型、校验及结果。五折指标、训练/验证seed、迭代次数和校准保存完整；未保存逐行OOF概率及五个折模型，只保存最终全40seed模型和256项核对。原绑定代码与数据支持重跑，本轮没有独立重建每个OOF向量。

下一步若采用该预测，先固定一种出牌攻防用法，在新的开发seed上比较完整净分；不能直接把概率误差降低当作牌力提高。对手真实拿牌与弃牌选择可能改变分布，情景加番、合法胡是否接受和本家进攻损失都仍须处理。正式留出候选、门槛、源码和新的未用seed尚未选定。

## 首次实战接入未通过

V11已把固定模型与短摸进攻代理组合，在新的20开发seed完整执行1440局。相比同组V10，平均每局−0.5625，诊断区间[−0.9254,−0.1996]；少点炮付款不足以抵消自摸/点胡收入损失和对手自摸付款增加，因此不晋升。该组合并未隔离分类器的单独作用，但明确说明旧数据预测误差改善不能当作实战净分改善。完整方法、全部负面分层与证据见[V11报告](INDEPENDENT_BENCHMARK_V11.md)。

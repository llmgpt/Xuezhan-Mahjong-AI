# 自动托管与复盘

## 使用方式

- 玩家牌桌底部的“自动托管”代替本家完成换三张、定缺、出牌及碰杠胡响应。三名电脑对手仍按玩家对局流程行牌。默认在每次本家决策前等待 **3 秒**，“牌局设置 → 托管节奏”可选 1、3、5 秒。
- 点击“暂停托管”可接管当前牌局；手动选牌或操作也会停止托管。打开设置、建议依据或复盘会暂停托管。
- 点击“本局复盘”查看本家每次决策前的手牌、定缺、公开信息、实际选择、当时建议、备选、理由与局限。结算面板也有复盘入口；“关键步骤”可快速定位偏离建议、碰杠胡或积分变化。
- 清完缺门后，可在出牌建议详情或该步复盘中点击“比较未来两次摸牌”。分析只用行动时保存的本家手牌和公开信息，比较推荐牌与备选牌；复盘不会借用后来实际摸到的牌。
- 打出万、条、筒时会中文报牌。换三张、定缺和清缺门只报结果；其他本家选择朗读行动时保存的简短结论，偏离建议时简短提示推荐项。碰、杠、胡和结算也有简短语音与轻量提示音。完整理由仍保存在本局复盘中，“查看依据”弹窗可主动朗读当前推荐理由。托管等待本步语音结束后再按 1/3/5 秒节奏继续。三名电脑的公开动作也会报牌，连续动作只播最近几步，避免语音积压。“牌局设置 → 声效与中文报牌”可关闭；“中文朗读声音”列出当前浏览器提供的中文声音，可逐个试听，选择与静音开关保存在当前浏览器。自动选择优先使用本机普通话，语速为正常值。在线声音可能调用浏览器的远程语音服务；没有语音支持时牌局仍可操作。

## 策略和解释边界

本家托管使用现有动作与出牌建议：优先合法胡牌，比较碰后的弃牌和未知补牌前的杠牌结构，按向听、进张粗估等选择出牌。换三张沿用简单基线：按万、条、筒顺序选第一门足够三张的花色，取该门手牌中的前三张；定缺选张数最少的一门，张数并列按上述顺序。本阶段没有训练模型；按需打开的两摸前瞻暂不改变托管和建议排序。其余三家的碰杠策略沿用原有规则。

策略只接收本家受限视图，不读取对手暗牌或真实牌墙顺序。记录在行动时生成，保存独立的当时视图与候选解释；语音和复盘直接使用记录，不根据后来摸到的牌重新计算理由。操作后的公开结果与积分变化单独列出。响应选择可能等待其他人提交，申请碰杠不表示最终获得该面子。

“关键步骤”标记与建议不同的选择、碰杠胡及发生积分变化的步骤，不判定这些动作一定正确或错误。进张、收益、风险仍是启发式粗估，不表示精确概率。

两摸前瞻从本家视图扣除已见牌，枚举下一张可能摸到的牌；若不能直接胡，则在合法弃牌中选择两摸模型下成胡占比最高的延续。未见牌既可能在墙中，也可能在对手暗牌中；模型假设从未见牌均匀摸取，不处理对手在两次本家摸牌之间的弃牌、碰杠胡、点炮、番型和支付。显示的百分比只用于比较这个简化模型，不能当作真实胡牌率或净分预测。清缺门阶段与牌墙不足两张时不显示。

## 存储与验证

牌局和记录只保存在当前页面内存中，刷新或重新开局会清空记录；没有跨设备存储、牌谱导入导出或外部解析服务。

src/game/decision.test.ts 覆盖本家专属决策、托管到结算、108 张牌与积分零和、对手暗牌隔离、玩家偏离推荐及决策快照独立性；src/game/lookahead.test.ts 覆盖前瞻的可见张数和清缺门边界。运行 npm run check 验证格式、静态检查、类型、单元测试和生产构建。自动浏览器 CI 仍待接入。

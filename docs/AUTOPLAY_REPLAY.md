# 自动托管与复盘

## 使用方式

- 玩家牌桌底部的“自动托管”代替本家完成换三张、定缺、出牌及碰杠胡响应。三名电脑对手仍按玩家对局流程行牌。默认在每次本家决策前等待 **3 秒**，“牌局设置 → 托管节奏”可选 1、3、5 秒。
- 点击“暂停托管”可接管当前牌局；手动选牌或操作也会停止托管。打开设置、建议依据或复盘会暂停托管。
- 点击“本局复盘”查看本家每次决策前的手牌、定缺、公开信息、实际选择、当时建议、备选、理由与局限。结算面板也有复盘入口；“关键步骤”可快速定位偏离建议、碰杠胡或积分变化。
- 打出万、条、筒时会中文报牌；碰、杠、胡和结算也有简短语音与轻量提示音。三名电脑的公开动作也会报牌，连续动作只播最近几步，避免语音积压。“牌局设置 → 声效与中文报牌”可关闭，开关会保存在当前浏览器。中文语音由浏览器提供，缺少语音支持时牌局仍可操作。

## 策略和解释边界

本家托管使用现有动作与出牌建议：优先合法胡牌，比较碰后的弃牌和未知补牌前的杠牌结构，按向听、进张粗估等选择出牌。换三张沿用简单基线：按万、条、筒顺序选第一门足够三张的花色，取该门手牌中的前三张；定缺选张数最少的一门，张数并列按上述顺序。本阶段没有训练模型或未来摸牌搜索。其余三家的碰杠策略沿用原有规则。

策略只接收本家受限视图，不读取对手暗牌或真实牌墙顺序。记录在行动时生成，保存独立的当时视图与候选解释；复盘直接展示记录，不根据后来摸到的牌重新计算理由。操作后的公开结果与积分变化单独列出。响应选择可能等待其他人提交，申请碰杠不表示最终获得该面子。

“关键步骤”标记与建议不同的选择、碰杠胡及发生积分变化的步骤，不判定这些动作一定正确或错误。进张、收益、风险仍是启发式粗估，不表示精确概率。

## 存储与验证

牌局和记录只保存在当前页面内存中，刷新或重新开局会清空记录；没有跨设备存储、牌谱导入导出或外部解析服务。

src/game/decision.test.ts 覆盖本家专属决策、托管到结算、108 张牌与积分零和、对手暗牌隔离、玩家偏离推荐及决策快照独立性。运行 npm run check 验证格式、静态检查、类型、单元测试和生产构建。自动浏览器 CI 仍待接入。

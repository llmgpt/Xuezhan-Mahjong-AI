# 独立策略评测 V5：拆分弃牌与碰杠胡

> 更新于 2026-10-19。首轮 8 个旧开发种子、960 局已完成并独立审计。D（高级弃牌＋老师动作）相对老师 +0.8021 分/局，95% 近似区间 [0.2595,1.3446]，但收益集中在高级对手阵容，尚无正式通过。已从同一 82 项快照扩大到 40 旧开发种子、4,800 局。页面仍用旧老师。

## 问题与组合

V4 的统一收胡没有证实优于原高级。高级参考相对老师在内部阵容收益较大，但本家定缺的隔离差值接近零；因此下一步检查实际弃牌和碰杠胡的条件贡献。不能仅据先前整套策略的分数，把收益归给某一个模块。

保留如下五个 ID，全部共用老师换三张。T/E/D/K 也共用老师定缺；A 保留原高级定缺。原高级、V4 和产品页策略都不改。

| 简称 | ID                              | 实际弃牌排序 | 自摸、自杠及对外响应 |
| ---- | ------------------------------- | ------------ | -------------------- |
| T    | `teacher-v1`                    | 老师         | 老师                 |
| A    | `ebony72-advanced-public-v1`    | 原高级       | 原高级               |
| E    | `candidate-advanced-opening-v5` | 原高级       | 原高级               |
| D    | `candidate-advanced-discard-v5` | 原高级       | 老师                 |
| K    | `candidate-advanced-actions-v5` | 老师         | 原高级               |

D 先问老师：老师选择胡或杠就保留，老师选择弃牌时才用高级弃牌；对外响应始终用老师。调用高级弃牌时，显式在独立 view 副本中清空两类自杠候选，保持实际手牌、公开前史及合法弃牌不变。它是有明确动作限制的消融，不声称与未限制自杠时的整套高级策略完全相同。

K 先问高级：保留高级的胡和杠；若高级选择弃牌，再取老师候选中的第一项弃牌，不能误用老师推荐的另一杠。所有对外响应由原高级决定，包含上游的拒胡行为。高级回调收到深复制的公开 view，不能改动调用者或老师随后排序使用的独立快照。非预期动作、worker 错误及非法动作显式失败，不回退到旧策略。

实现见 [advancedComponents.ts](../src/game/advancedComponents.ts) 和[注册](../scripts/independentPolicies.ts)。这些 ID 只用于离线实验，没有据此增加页面“高级”开关。

## 预定开发网格

只用已花的 `80000..80007`：五策略、四座位、初级/高级/内部老师三阵容、共同/组合两开局，共 **960 局**。每比较 **192 配对**，统计独立单元为 **8 个种子**。另保留全部开局、阵容及收入分解。

预定六项比较全部报告：

- E−T：同老师开局后替换完整中后期策略。
- D−T：老师动作规则下替换高级弃牌。
- K−T：老师弃牌排序下替换高级动作规则。
- E−A：共同开局应逐轨迹一致；组合开局检查替换本家定缺的影响。
- E−D：使用高级弃牌时，替换动作规则的条件效果。
- E−K：使用高级动作规则时，替换弃牌排序的条件效果。

模块可能有交互作用，D−T 与 K−T 不必相加等于 E−T。动作改变后的摸牌归属和后续局面也会变化；整局配对差值不是每个具体动作的最优标签。

运行前固定母配置、四个不重叠分片和精确源码字节。各片两种子，每种子完整 120 局后才提交。T/A 控制本轮重新执行，不把不同源码指纹的旧成绩悄悄混入。全部分片完成、来源/运行时/规则一致、无缺失重复失败后再严格合并；使用固定的种子聚类 SE 与均值 ±1.96SE 正态近似区间，不能挑选有利阵容或节点。

计划已在运行前写入忽略的 `local/strength-goal-20261018/`：`development-v5.config.json`、`development-v5-shard-plan.json`。82 项生产源码的原字节快照为 `development-v5-source/`；[版本化协议](benchmarks/independent-v5-development-protocol.json)保留全部配置和源码指纹。原始日志需保留所有决定与完整公开前史。独立核验全部首分歧与共同开局 E/A 的轨迹一致性，除净分外同时报告合法性、牌数和积分守恒。

## 实现验证

注册先出现 3 项未知新 ID 的预期失败，接入后 14 项通过；组合器未实现时 28 项失败，实现并补齐真实补杠回归后 29 项通过，合计 43 项定向测试。真实宿主牌例覆盖自摸、多个暗杠、补杠、碰后短手牌、拒胡、公开 view 深层修改隔离、阶段错误及异常传播。

Root 完整 `npm run check` 已通过格式、lint、类型、35 文件 302 项测试和生产构建；Python 58 项另行通过。这些证明工程合同，不证明新组合更强。

独立审查另以 12 个已有开发公开帧完成 34 次实际高级调用，14 个 worker 均正常 finish；四文件哈希全程一致，两生产文件匹配快照，原 wire、适配与 vendor 共 42 文件匹配 V4。原始审查位于忽略的 `advanced-components-v5-review/`。四个真实分片都以退出码 0 完成，进程记录为 `development-v5-execution.json`。完整来源、82 项执行字节和全部分歧再次核验通过。

## 首轮完整结果

[版本化摘要](benchmarks/independent-v5-development-summary.json)保留全部配置、82 项指纹、72 项比较、收入与来源审计。每比较 192 配对，统计单元仅 8 个完整旧开发种子，使用原固定 SE 和正态区间，不做 bootstrap。

| 比较 | 均值差/局 | 95% 正态近似区间  |
| ---- | --------: | ----------------- |
| E−T  |   +0.1250 | [-0.7426, 0.9926] |
| D−T  |   +0.8021 | [0.2595, 1.3446]  |
| K−T  |   -0.9948 | [-1.9941, 0.0045] |
| E−A  |   +0.0260 | [-0.0250, 0.0771] |
| E−D  |   -0.6771 | [-1.5794, 0.2252] |
| E−K  |   +1.1198 | [0.3335, 1.9061]  |

D−T 的 156 个首分歧全部是在相同完整前史和当前公开 view 下弃牌改另一张合法弃牌，涉及 65 个不同 view；36 对完整轨迹一致。总净差 +154，自摸 +27、点胡 +85、放铳付款 -51、支付他家自摸 +65、杠钱 +20、查叫 +8。付款项目正数表示支出减少，因此放铳支出实际增加，不能概括为所有攻守指标都改善。

D 对初级、高级、内部老师阵容的均值差分别为 -0.0469、+2.7344、-0.2813；高级阵容区间 [1.0291,4.4396]，其他两项跨零。总收益由高级阵容 +175 抵消其他阵容 -21 得到。八个旧种子和 72 项未经多重比较校正的分层不能替代正式留出，更不能据单一阵容宣布高手水平。

K−T 有 116 个首分歧（108 响应、8 自杠），涉及 59 个 view。其自身 225 次合法胡机会中接受 107、拒绝 118；但按首分歧“老师胡、K过/碰”分类的后续整局净差仅 -30，其余分组合计 -161，不能把总净差 -191 全归因拒胡。各组只是完整轨迹的描述性分类，不是动作因果价值。

E−D 的 112 个首分歧为 104 响应与 8 自杠，没有观察到双方都弃牌却不同的首分歧；不推广为 mask 在所有未来局面都无影响。E/A common 96 对完整轨迹全部相同，composite 93 对同定缺轨迹相同，另 3 对首分歧均为本家定缺。T/A 的 384 项完整结果和轨迹逐项精确复现 V4。

四片来源各 240 局，完整网格、零和、收入与全轨迹内容核对一致；独立分析器 0 硬异常、0 mask 偏离，原分析文件和日志未改。Root 另重算 12 面板、72 比较全部吻合，冻结 CLI 续跑 8 种子全部跳过。后续 cap8 代码已与本轮快照隔离，当前工作区不冒称与旧 82 项全部相同。

## 40 旧开发种子的固定复核

运行前固定 `60000..60039`，保留全部 T/A/E/D/K 五策略和六项比较，包括首轮表现差的 K；四座位、三阵容、两开局，共 **4,800 局**。每种子完整 120 局才提交，四片按索引轮流分配，每片 10 种子、1,200 局。新一轮与 8 种子诊断分开报告。

[扩大协议](benchmarks/independent-v5-expanded-protocol.json)记录全部配置、82 项执行指纹和分析方法；忽略目录下 `development-v5-expanded.config.json`、`development-v5-expanded-shard-plan.json` 与 `development-v5-expanded-execution.json` 保存实际运行配置和进程句柄。四片已从同一 `development-v5-source/` 启动，各 manifest 均与声明精确一致，当前仍在计算；不会按有利中间成绩提前终止。

仍只使用 40 个已花开发种子的聚类 SE 与正态近似区间，全部完整后汇总，不新增 bootstrap。任何错误明确保留，不丢种子或静默回退。没有加入 cap8、新外部策略或新正式通过标准。

## 边界与下一步

这轮只定位模块，8 个已花种子的区间不作为正式通过标准。即使某组合表现较好，也要先扩大开发覆盖、确认运行成本和实际原因，再冻结新的正式留出；初级与高级对手同源，仍缺可信高手标尺。浏览器已有 Python 核心兼容性探针，未完成候选产品整局接入。

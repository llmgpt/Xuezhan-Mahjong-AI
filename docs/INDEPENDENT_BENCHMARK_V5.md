# 独立策略评测 V5：拆分弃牌与碰杠胡

> 更新于 2026-10-20。40 个已花开发种子、4,800 局已完整完成并独立审计。E 相对老师 +0.5094 分/局，95% 正态近似区间 [0.0742,0.9445]；D 相对老师、E 相对 D 的区间均跨零。初级与高级参考同源，尚无正式通过或高手结论。早期 8 种子结果单独保留，页面接入仍需另验收。

## 问题与组合

V4 的统一收胡没有证实优于原高级。高级参考相对老师在内部阵容收益较大，但本家定缺的隔离差值接近零；因此下一步检查实际弃牌和碰杠胡的条件贡献。不能仅据先前整套策略的分数，把收益归给某一个模块。

保留如下五个 ID，全部共用老师换三张。T/E/D/K 也共用老师定缺；A 保留原高级定缺。原高级、V4 和产品页策略都不改。

| 简称 | ID                              | 实际弃牌排序 | 自摸、自杠及对外响应 |
| ---- | ------------------------------- | ------------ | -------------------- |
| T    | `teacher-v1`                    | 老师         | 老师                 |
| A    | `ebony72-advanced-public-v1`    | 原高级       | 原高级               |
| E    | `candidate-advanced-opening-v5` | 原高级       | 原高级               |
| D    | `candidate-advanced-discard-v5` | 原高级       | 老师                 |
| K    | `candidate-advanced-actions-v5` | 老师         | 原高级               |

D 先问老师：老师选择胡或杠就保留，老师选择弃牌时才用高级弃牌；对外响应始终用老师。调用高级弃牌时，显式在独立 view 副本中清空两类自杠候选，保持实际手牌、公开前史及合法弃牌不变。它是有明确动作限制的消融，不声称与未限制自杠时的整套高级策略完全相同。

K 先问高级：保留高级的胡和杠；若高级选择弃牌，再取老师候选中的第一项弃牌，不能误用老师推荐的另一杠。所有对外响应由原高级决定，包含上游的拒胡行为。高级回调收到深复制的公开 view，不能改动调用者或老师随后排序使用的独立快照。非预期动作、worker 错误及非法动作显式失败，不回退到旧策略。

实现见 [advancedComponents.ts](../src/game/advancedComponents.ts) 和[注册](../scripts/independentPolicies.ts)。这些 ID 只用于离线实验，没有据此增加页面“高级”开关。

## 预定开发网格

只用已花的 `80000..80007`：五策略、四座位、初级/高级/内部老师三阵容、共同/组合两开局，共 **960 局**。每比较 **192 配对**，统计独立单元为 **8 个种子**。另保留全部开局、阵容及收入分解。

预定六项比较全部报告：

- E−T：同老师开局后替换完整中后期策略。
- D−T：老师动作规则下替换高级弃牌。
- K−T：老师弃牌排序下替换高级动作规则。
- E−A：共同开局应逐轨迹一致；组合开局检查替换本家定缺的影响。
- E−D：使用高级弃牌时，替换动作规则的条件效果。
- E−K：使用高级动作规则时，替换弃牌排序的条件效果。

模块可能有交互作用，D−T 与 K−T 不必相加等于 E−T。动作改变后的摸牌归属和后续局面也会变化；整局配对差值不是每个具体动作的最优标签。

运行前固定母配置、四个不重叠分片和精确源码字节。各片两种子，每种子完整 120 局后才提交。T/A 控制本轮重新执行，不把不同源码指纹的旧成绩悄悄混入。全部分片完成、来源/运行时/规则一致、无缺失重复失败后再严格合并；使用固定的种子聚类 SE 与均值 ±1.96SE 正态近似区间，不能挑选有利阵容或节点。

计划已在运行前写入忽略的 `local/strength-goal-20261018/`：`development-v5.config.json`、`development-v5-shard-plan.json`。82 项生产源码的原字节快照为 `development-v5-source/`；[版本化协议](benchmarks/independent-v5-development-protocol.json)保留全部配置和源码指纹。原始日志需保留所有决定与完整公开前史。独立核验全部首分歧与共同开局 E/A 的轨迹一致性，除净分外同时报告合法性、牌数和积分守恒。

# V8：按当前等待牌比较收胡金额

**候选已实现并通过固定牌例与接入检查，尚未取得整组强度结果。** `candidate-advanced-ready-income-v8`继承V7的老师开局和高级行牌，只替换合法点胡的`check_hu`。它按本桌实际付款逐牌计价，同时删除原函数中推测碰后金钩、清一色、多步伪等待及未来杠钱的比较项；不是只改一个倍率，也不是完整续局期望净分。

当前页面默认老师、浏览器E/D和原T/A/E/V7保留；V8仅用于离线评测。没有新正式种子、默认策略提升或高手水平结论。

## 明确的金额模型

当前暗手`H`仍为`13−3m`张，`M`是真实本家副露，`t`是宿主允许胡的当张弃牌。由`H+[t]`、`M`和实际当前事件求一名点炮者会付的收入`C0`；当前弃牌只加一次，不能放回未来未见牌KB。

对每种`KB[x]>0`的牌，以真实`H+[x]`、`M`计算合法完成形的V1分值`Qx`。每家未来自摸付款是封顶后的`Qx+1`；不同等待牌可能有不同根、番型和封顶，按KB张数加权。当前未胡对手数`N`已经包含在原来的机会因子中，不再乘第二次：

```text
W = 当前余墙，K = ΣKB，r = W/(N+1)
F = N × .99^(55−W) × (1−.8^r) / (K × (1−.8))
U = Σ合法完成牌 KB[x] × (Qx+1)
等待比较值 = F × U / C0
```

比较值大于固定门槛1才拒胡，否则收胡。保持原因子的浮点运算次序，没有拟合折扣、截断为概率或调整阈值。墙尽时未来项为0；仅剩1张墙牌时，条件未来自摸必带海底番；余墙多于1张时采用普通无事件情形，尚未为未来末张分配混合权重。

当前杠后炮和海底只进入`C0`，不复制到未来自摸，也不再后乘V7的`B0/C0`。当前海底要求墙尽且待响应弃牌的紧前公开动作是同一人的摸牌；原末张摸牌者后来再碰又弃，不会继续保留海底。已有杠计入真实副露和根，已付杠钱不重复计入，四副露没有额外金钩番。

原`check_robkong`、弃牌、自摸、碰杠等仍为V7的原函数对象；新facade不改A/V7共享全局。新函数共享V8模块自身的globals，并非每个facade拥有私有globals。若本次拒胡，后续原策略仍可能选择碰或杠，改变真实手牌；静态等待模型没有为这条后续路径估价。错误显式失败，不回退其他策略掩盖问题。

机会因子仍是未校准近似。未来他家胡牌、付款人数变化、摸牌次序、支付他人及流局风险尚未建模，删去旧推测项也可能丢失有用的远期机会。金额算术自洽不代表动作更强，详见[未来收益审计](ADVANCED_FUTURE_INCOME_AUDIT.md)。

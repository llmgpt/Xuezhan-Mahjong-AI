# 血战到底规则 V1

本文是本项目的**规则目标**，不是已实现功能清单。四川各地及平台有差异；以下选择构成可复现的第一版教学牌桌。实现状态见 [README](../README.md) 与 [下一步](NEXT_STEPS.md)。参考了[浙江游戏大厅的血战规则](https://www.hzbianqu.com/game/1100.html)和[麻將國当前牌桌说明](https://mahjongo.com/zh/sichuan)；两者在自摸加底或加番等处不同，因此本项目把具体选择写在下面。

## 牌、座次与开局

| 项目     | V1 选择                                                                                      | 可配置方向                   |
| -------- | -------------------------------------------------------------------------------------------- | ---------------------------- |
| 人数与牌 | 4 人；万、条、筒各 1–9，每种 4 张，共 108 张；无字牌、花牌                                   | 其他人数另立规则配置         |
| 庄家     | 单局座位 0 为庄，座位按 0→1→2→3 轮转；庄起手 14 张，其余各 13 张，牌墙余 55 张               | 连局时庄家轮换规则           |
| 洗牌     | 带整数种子的确定性洗牌；同种子与同规则配置重现同局                                           | 洗牌算法版本需记录在牌谱中   |
| 换三张   | 每人同时选**同一花色**的 3 张手牌；都提交后同时顺时针传给下一座（0→1）；不得先看别人换来的牌 | 逆时针、对家或随种子抽取方向 |
| 定缺     | 换牌结束后每人同时选万、条、筒中的一门；可以选手里已没有的花色；本局不可改                   | 是否必须选现有花色           |

牌墙按洗牌后的顺序摸取，不预留王牌。整个对局中的牌始终应恰好有 108 张，位于牌墙、手牌、弃牌、明暗杠/碰的牌组或已胡者保留牌中。

## 行牌与响应

庄家在定缺完成后先打一张；其后未胡的下家摸一张、打或胡。每次弃牌后先收集其他未胡玩家的响应，再确定下一步。不能吃。玩家手里仍有定缺门牌时，只能打该门牌；定缺门牌不可参与碰、杠或胡。手里仍有缺门牌时可碰/杠**非缺门牌**，随后打牌仍须先打缺门；胡牌则必须已清空缺门牌。

- **碰**：持两张同牌，认领别人的弃牌，亮出三张，然后自己打牌；不从墙摸。**直杠**：持三张同牌，认领别人的弃牌，亮出四张，先从墙尾补一张再打牌。**暗杠**：在自己的摸打回合用四张手牌开杠；**补杠**：把自己的明碰加上新摸到的第四张。暗杠与补杠同样从墙尾补牌。墙中无牌时不得开杠。碰/杠不能使用定缺门牌。
- **胡**：标准型为四组顺子或刻子加一对，或七对；七对中的四张同牌可算两对。有已亮出的面子时只检查剩余所需面子。不得有定缺门牌。自摸与别人打出的牌都可胡；补杠牌可抢杠胡。抢杠成功则补杠不成立。
- **响应优先级**：同一弃牌的多家胡全部成立（座次顺序记账）；胡高于杠，杠高于碰。多人同时要求碰/杠时，按从弃牌者起顺时针距离最近者获得。所有人放弃才轮到未胡的下家摸牌。放弃胡牌不设置过手胡限制；以后可再胡。最后一张墙牌摸出后可以胡和碰，但不能杠。
- **胡后血战**：胡牌者退出摸打及响应，保留其牌和已结算分；下一位未胡者继续。三家胡牌即刻结束，最后一人无需胡。牌墙用尽时，在最后一张摸牌所引发的打牌及胡/碰响应结束后结束。

以上响应、胡后继续和杠牌流程属于后续实现范围，不能从规则目标推断已可在页面操作。

## 番型与支付目标

底分为 1。平胡 0 番；对对胡 +1，清一色 +2，七对 +2，每个根（同一玩家手牌及面子里四张同牌）+1；杠上花、杠后炮、抢杠胡、海底胡各 +1。七对与对对胡互斥；同一根不能因拆分方式重复计。其余番型暂不计。累计番数封顶 3，牌型分为 `2^min(番数, 3)`。点炮由点炮者单独付牌型分；自摸由当时每位未胡对手各付 `牌型分 + 1`。同一弃牌多家胡，点炮者分别支付。支付是零和转账。

杠钱独立于胡牌：直杠由出牌者付 2；暗杠由当时每位未胡对手各付 2；补杠由当时每位未胡对手各付 1。被抢的补杠不收费。首版不启用呼叫转移、退税、过手杠、门清加番、天胡/地胡及自摸加番；这些均需要单独的规则开关及牌例，不应偷偷计入上述公式。

## 流局结算目标

墙尽且响应处理完毕后，仅对尚未胡牌的人结算。先查花猪：仍持有自己定缺门牌者是花猪，向每位非花猪、未胡玩家支付封顶牌型分 8；已胡者不参加流局检查。然后查叫：非花猪玩家若没有任何一张可形成合法胡牌的等待牌，则向每位非花猪的听牌者支付该听牌者所有可胡等待牌中最高的封顶牌型分；没有听牌者则不发生查叫支付。结算按流局时手牌与已亮出面子判断，测试牌例固定可用牌范围；查叫不计自摸加底。花猪不再参与查叫。已收的胡牌与杠钱保留；首版不退税。若同一玩家理论上有多种分解，采用最高合法番型。

## 实现边界和验收牌例

第一代码切片实现 108 张牌、种子洗牌、发牌、换牌、定缺、定缺强制出牌、摸打状态与牌数守恒；胡牌结构判定和结束条件先作为独立规则能力验证。碰、杠、胡的完整响应流程及上述计分、流局结算暂不接入对局，不把这段切片称为可完成一局的版本。

代表性牌例在 `src/game/*.test.ts` 固定：同种子发牌一致且各牌恰好四张；四人换牌后牌数不变；缺门未打完只能打缺门；`111万 234万 345条 678条 99筒` 可标准胡，七对可胡，持有定缺门不能胡；三家胡或墙尽才结束。新规则接入对局前补充碰杠响应、多人胡、番型支付和查叫的失败测试。

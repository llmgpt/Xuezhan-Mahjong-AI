# 自动打牌、教学观战与复盘

## 使用方式

- 玩家牌桌底部的“自动托管”代替你完成换三张、定缺、出牌和碰杠胡响应；“暂停托管”可随时接管，手动操作也会停止托管。
- 点击“教学观战”进入四电脑牌桌。点击“自动播放”逐步观看，支持暂停、上一/下一步和 1、2、4 倍速度。“自动打完本局”分批运行到结算，期间仍能暂停。
- 观战牌桌显示当前步骤**操作完成后**的四家手牌；解析显示该行动者**操作前**的手牌、定缺、公开信息、实际选择、推荐、备选与局限。
- 窄屏内可点击“本步解析”和“查看牌桌”快速切换滚动位置，播放控制始终保留在顶部。
- 结束后自动汇总决策次数和关键步骤，可打开复盘报告逐步查看；“从开局回看”使用已有记录回放。玩家模式也可从底部或结算面板打开本局复盘。打开复盘会暂停自动播放或托管。
- 观战设置可输入安全整数种子重新开局。同种子、同规则和同策略版本会复现相同对局。返回玩家练习会保留原玩家牌局；再次进入观战会开始新的教学局。

## 策略和解释边界

四电脑观战与玩家本家托管使用现有动作/出牌建议：优先合法胡牌，比较碰后的弃牌和未知补牌前的杠牌结构；按向听、进张粗估等选择出牌。换三张沿用简单基线：按万、条、筒顺序选第一门足够三张的花色，取手牌中的前三张；定缺选张数最少的一门，张数并列按上述花色顺序。本阶段没有训练模型或未来摸牌搜索。玩家练习中其余三家的碰杠策略仍沿用原有规则，可能与观战模式不同。

教学界面明确标记全手牌视角，策略只接收行动者的 `PlayerView`，不读取对手暗牌或真实牌墙顺序。记录在行动时生成，保存独立的当时视图与候选解释；复盘直接展示记录，不根据后来摸到的牌重新计算理由。操作后的公开结果与积分变化单独列出。响应选择可能等待其他人提交，申请碰杠不表示最终获得该面子。

“关键步骤”标记与建议不同的选择、碰杠胡及发生积分变化的步骤，不判定这些动作一定正确或错误。玩家复盘记录本家的决策；观战记录四家行动及摸牌流程。进张、收益、风险仍是启发式粗估，不表示精确概率。

## 存储与验证

牌局和记录只保存在当前页面内存中，刷新、重新开局或离开观战会清空该模式的记录；没有跨设备存储、牌谱导入导出或外部解析服务。

`src/game/teaching.test.ts` 覆盖从开局到结算的自动流程、逐步/连续执行复现、108 张牌与积分零和、胡后退出、优先胡牌、玩家偏离推荐以及决策快照独立性。运行 `npm run check` 验证格式、静态检查、类型、单元测试和生产构建。浏览器验证覆盖教学播放/暂停/单步/结算/历史回放与玩家托管/复盘/重开；自动浏览器 CI 仍待接入。

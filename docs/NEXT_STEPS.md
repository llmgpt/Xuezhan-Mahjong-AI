# 新对话开发交接

> 更新于 2026-09-29。实际完成情况以仓库代码和测试结果为准。

## 当前状态

- 项目是面向学习的四川血战到底网页游戏，公开仓库为 [llmgpt/Xuezhan-Mahjong-AI](https://github.com/llmgpt/Xuezhan-Mahjong-AI)。
- 本地可试玩 V1 已能让玩家与三名电脑完成一局：换三张、定缺、摸打、碰杠胡、血战继续、番型与流局结算均在页面操作。具体取舍见 [规则表](RULES_V1.md)。
- 出牌建议展示推荐与备选、向听和进张粗估、收益倾向、风险提示与局限。建议和电脑只读取本家手牌及公开信息，是启发式策略，不是训练模型。
- 支持整数种子复现发牌和电脑选择；固定牌例与整局模拟检查牌数和积分守恒。运行和检查命令见 [README](../README.md)。
- 复盘、四电脑教学观战、账号、多人联网和公开网页部署尚未实现。个人安装的开发 skill 与 Serena MCP 不是运行依赖。

## 下一项开发任务

**围绕可试玩 V1 做真实牌例验收，再加入复盘。**

1. 用更多真实对局和固定种子核对地区规则差异，尤其查叫的实际可用牌定义、复杂抢杠和杠钱。发现差异先更新 [规则表](RULES_V1.md)，规则、计分、流程或建议行为变更先写失败测试。
2. 将本地浏览器整局操作检查纳入自动化，覆盖开局、响应、建议、结算及窄屏布局；CI 目前只有单元牌例、静态检查和构建。
3. 复盘记录每次玩家决策时**当时可见**的手牌、公开信息、实际动作和系统建议；回放不能用后续牌面解释旧决策。
4. 再做四电脑教学观战，明确标记全手牌视角；公开网页部署在验收后进行。

建议的向听、进张、收益和风险目前是粗估；有缺门牌时页面暂缓报告向听。不要把这些数字描述为精确获胜率或放铳概率。模块边界见 [架构草图](../ARCHITECTURE.md)，开发验证流程见 [开发与反馈回路](ENGINEERING.md)。

## 新对话怎么开始

在项目目录开启新对话，说明要核对的规则牌例或复盘范围即可；先核对仓库现状与相关文档。本页提供交接，不替代实际代码、测试和规则文档。

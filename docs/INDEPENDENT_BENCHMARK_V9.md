# V9：普通点胡节点的完整净分续局

**候选已实现并完成工程检查，尚无整组实战强度结果。** `candidate-advanced-ron-continuation-v9`只拦截本家合法普通点胡响应；它比较现在胡的确定实收，以及过、碰、杠各合法选择之后的完整净分。其余节点精确沿用V8的full组件，包括老师开局及原Python行牌。页面默认策略没有改变，V9尚未接入生产浏览器，也未开始新的正式留出。

## 为什么继续这一方向

[V8完整诊断](benchmarks/independent-v8-diagnosis.json)已逐个复算全部130个分歧、92个完整公开context，V7→V8→V7动作与原始轨迹一致。所有改动都是拒胡改为收胡：原动作72个过、52个碰、6个杠。56个配置整局正差、54个负差、20个相同，合计仅+1分；它们来自37个已有seed，不能把130个配置或92个节点当作独立样本。

V8整局收付差中，自摸少395分，点胡多180分，点炮和付他家自摸分别少付75/187分，杠钱少32、查叫少14分。这说明后续机会和继续支付风险都值得建模；这些是完整配对终局关联，不是第一动作的因果价值，也不能据此写“某收入档一律胡/拒胡”的最优规则。原始模型分支、全部正负节点与SHA保留在忽略的`local/strength-goal-20261018/ready-income-v8-diagnosis/`。

## 固定的模型和选择规则

本桌V1的合法点胡给本家确定的单家付款`C0`。本家成胡后退出后续摸打、杠钱和流局收付，因此无需再模拟一个胡分支；当前实收不乘其他活跃人数，也不把此前已有积分重复加入。

每个公开生成世界中，分别执行全部合法非胡响应，再由原老师继续至正常结算，得到本家相对当前分数的净增量`X[a,i]`。所有胡、过、碰、杠选择都保留，不只比较静态原手等自摸。

```text
当前胡值 = C0（确定常数）
每个非胡动作模型值 = mean(X[a,*]) − 2 × 模型Monte Carlo标准误
只有最高模型值严格高于 C0 才拒胡；并列或波动不可估时胡
```

固定8个粒子，每个动作/粒子最多3000个宿主转换，参数在读取全部92节点的新续局值前另存`ron-continuation-v9-proposal.json`。2个标准误只是固定的保守启发式，未校准为真实胜率或置信区间；粒子标准误不包含模型偏差。单粒子无法估计随机分支波动，不能填0。与常数胡值相减也没有额外配对降噪。

联合采样无解或耗尽预定预算时，记录明确的0样本fallback并收取当前合法胡；不冒称完成了比较。非法公开历史、库存、错误数量、非有限/不守恒净分或续局未结算均显式失败，不能丢掉困难粒子、用中途分数或部分样本算成功。

## 信息边界和宿主重建

入口只收`PlayerView`。完整公开动作流核对13−3m暗手、已扣除的当前弃牌、公开库存和score；仍保留已胡者合法胡型、公开胡张及支付番数约束。每次真实摸牌撤销旧清缺证明，碰杠不被当成新证明。原self粒子入口和其随机序列保持，响应使用单独的版本标签。

在每个粒子的生成手牌上，复用同一V1规则helper重算所有响应资格，并创建空的模拟回答队列。真正未公开的他家资格、已提交回答及摸牌身份不可访问，也无法由当前视图恢复。其他家在新生成窗口重新回答；未来每个演员只接自己的生成视图，不接真实seed、牌墙或对手暗手。

续局包括多家胡优先、碰杠优先级、补摸、结束条件、未来胡牌/点炮/杠钱/查花猪/查叫；所有状态维持108张、每种4张和零和，未来转账与相对当前净分一致。杠后炮和海底来自完整公开事件；碰后墙尽弃牌不会保留过时海底。

这是有偏的联合生成模型，后续四家固定用原老师；它没有拟合真实高级/BA对手或对手历史择牌概率，不是完整后验。花色DP原型没有一并接入，不能把它的精确边际结论移作本模型的精确分布证明。

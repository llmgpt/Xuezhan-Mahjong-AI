# 浏览器高级策略接入

现有默认页面仍用老师。这里记录把离线已评测策略接回真实牌桌的工程进度，不把兼容测试当作实战提升。E保留老师开局及完整高级动作，D保留老师开局/胡杠/响应、仅实际弃牌调用高级；两者复用原 `chooseAdvancedComponentAction`，不另写一套组合规则。

`src/strategy/advancedClient.ts` 已提供单步异步服务。只传当前本家 `PlayerView` 和阶段，严格拒绝牌墙、其他暗手及未知字段；Python仍执行原高级公开接口。会话、局面版本和Worker运行代号用于拒绝旧输出，取消或错误会终止进行中的Worker，不能悄悄回退老师。正常完成后同会话的新局面复用空闲运行时，避免每张牌重新加载WASM。输入、资源参数和缓存结果均复制，调用者后续修改不能改变已经发出的请求。

Worker在独立线程加载明确的本地资源地址，验证38项Python闭包的逐文件摘要和挂载字节，再执行真实Python。客户端与Worker都按当时宿主合法动作检查返回值。结果仅有实际动作、阶段、策略出处与合法选择数等元数据；一条推荐不等于唯一合法动作，也没有高级风险概率、两摸收入或全动作评分表。

第一切片30项新测试覆盖E/D路由、拒胡保留、公开字段、异步输入快照、过期取消/重建、错误和空闲复用；根代理另实际重跑这30项与29项原组合测试，59项通过。独立代理在后续App/构建改动前完成46文件410项全量测试。这些检查的具体范围及源码哈希见[版本化准备证据](benchmarks/browser-policy-bridge-preparation.json)。

另从既存80000轨迹按阶段/动作类别选12个公开节点，真实本地Pyodide复算12/12动作相同，实际Python调用8次，覆盖高级实际弃牌、响应收胡/拒胡后碰、自摸和直杠，以及老师来源的D动作。该探针是Node中的进程内transport模拟，不是真浏览器Worker，也没有运行新局或新seed。Pyodide314.0.7本地8资产已与官方NPM包逐字节核对，完整归档integrity亦匹配；[固定来源的上游版本](https://github.com/pyodide/pyodide/tree/b1e4fcc2488962f6360a97f19b9982d6fdb5d16f)及许可来源保存在准备证据中。

## 实际牌桌与生产资源

App已接入同一份当前决策：荐牌、AdviceCoach、托管和推荐语音复用同一个结果。每次操作更新局面版本，新局更新会话；加载隐藏旧建议，错误停止托管并保留手动操作。旧异步输出与旧托管回调须通过当前版本门禁。只有实际老师来源才展示老师依据；高级来源显示真实动作出处与规则事实，手工其他动作只播报操作事实。高级单项首选与唯一合法动作明确区分，没有借用旧老师的两摸比较或评分解释。

`<App />`仍默认老师，`src/main.tsx`未提升默认策略。内部验证入口可传`strategyMode="E"|"D"`、明确的同站运行资源和首次`initialSeed`，没有在产品里增加实验算法设置。V7当前收益修正版先只接离线注册，不包含在浏览器E/D定义中。

构建插件从锁定的官方NPM `pyodide@314.0.7`验证8个运行时文件，并把38项Python原字节闭包、完整许可证和来源通知输出为17个固定同站资源；WASM以正确类型提供，开发子路径与HEAD也覆盖测试。没有把13MB运行时二进制放入Git。三项适配入口及宿主评分fixture明确保留Git原字节，避免换行转换使固定摘要在其他checkout失效。Root实际验证index经autocrlf开/关过滤后4个固定文件仍逐字节相同；原高级适配入口仅将既存CRLF字节保真入库，Python语义未改。

许可材料包括Pyodide MPL、CPython3.14.2完整许可证、两策略MIT及实际内嵌组件/工具链的12项通知。`vendor/pyodide-runtime/UPSTREAM.json`与`THIRD_PARTY_SOURCES.json`保留精确来源、摘要和范围；这不是重编二进制或逐对象认证整个工具链的结论。

2026-10-20用内置浏览器操作同一个真实App及生产打包Worker，在已排除的80000、seat0、ui-bots、composite配置完成E/D整局，四家得分分别为`[22,6,-9,-19]`与`[1,5,3,-9]`，均与对应Node结果及两条胡牌记录一致，牌墙摸尽、积分和为0。E还另在开发服务完整操作过一局；这些重复兼容局不增加强度样本。真实操作覆盖手动推荐弃牌、托管、设置/依据弹窗暂停、固定局重置、E/D模式切换；生产资源故意404时显示错误且托管禁用，仍可手动合法出牌，恢复资源后当前建议重建。

完整项目检查实际通过48文件431项TypeScript测试、format/lint/typecheck/生产构建；Python131项通过，含新离线候选。界面部分包含SSR与异步门禁测试，真实整局证据另见[牌桌QA记录](benchmarks/browser-production-integration.json)。本轮未导出浏览器完整逐步决策流，不把终局一致冒称全轨迹字节相同；全部高级响应分支、加载中手工换动作/新局/超时的真实GUI竞态、窄屏和实际听感仍需补验。详细内部评分和分支理由尚未采集，整体Goal仍未完成。

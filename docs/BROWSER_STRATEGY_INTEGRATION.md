# 浏览器高级策略接入

现有默认页面仍用老师。这里记录把离线已评测策略接回真实牌桌的工程进度，不把兼容测试当作实战提升。E保留老师开局及完整高级动作，D保留老师开局/胡杠/响应、仅实际弃牌调用高级；两者复用原 `chooseAdvancedComponentAction`，不另写一套组合规则。

`src/strategy/advancedClient.ts` 已提供单步异步服务。只传当前本家 `PlayerView` 和阶段，严格拒绝牌墙、其他暗手及未知字段；Python仍执行原高级公开接口。会话、局面版本和Worker运行代号用于拒绝旧输出，取消或错误会终止进行中的Worker，不能悄悄回退老师。正常完成后同会话的新局面复用空闲运行时，避免每张牌重新加载WASM。输入、资源参数和缓存结果均复制，调用者后续修改不能改变已经发出的请求。

Worker在独立线程加载明确的本地资源地址，验证38项Python闭包的逐文件摘要和挂载字节，再执行真实Python。客户端与Worker都按当时宿主合法动作检查返回值。结果仅有实际动作、阶段、策略出处与合法选择数等元数据；一条推荐不等于唯一合法动作，也没有高级风险概率、两摸收入或全动作评分表。

第一切片30项新测试覆盖E/D路由、拒胡保留、公开字段、异步输入快照、过期取消/重建、错误和空闲复用；根代理另实际重跑这30项与29项原组合测试，59项通过。独立代理在后续App/构建改动前完成46文件410项全量测试。这些检查的具体范围及源码哈希见[版本化准备证据](benchmarks/browser-policy-bridge-preparation.json)。

另从既存80000轨迹按阶段/动作类别选12个公开节点，真实本地Pyodide复算12/12动作相同，实际Python调用8次，覆盖高级实际弃牌、响应收胡/拒胡后碰、自摸和直杠，以及老师来源的D动作。该探针是Node中的进程内transport模拟，不是真浏览器Worker，也没有运行新局或新seed。Pyodide314.0.7本地8资产已与官方NPM包逐字节核对，完整归档integrity亦匹配；[固定来源的上游版本](https://github.com/pyodide/pyodide/tree/b1e4fcc2488962f6360a97f19b9982d6fdb5d16f)及许可来源保存在准备证据中。

下一步将同一当前决策接到App的荐牌、托管和语音；加载不能留旧荐牌，错误暂停托管且允许手动操作，手动动作/新局/取消后的迟到结果不得执行。只有本次实际来源是老师时才使用老师解释；高级来源先显示实际出处与规则事实，详细理由需另外采集真正计算分支，不能把老师依据追认给高级结果。运行时与Python包的同站构建输出、真实牌桌完整局、暂停/新局/过期与窄屏检查仍须另行完成。

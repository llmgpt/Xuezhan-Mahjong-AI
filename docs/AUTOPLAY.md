# 自动托管与实时建议

## 使用方式

- 牌桌底部的“自动托管”代替本家完成换三张、定缺、出牌及碰杠胡响应。三名电脑对手仍按玩家对局流程行牌。默认在每次本家决策前等待 **3 秒**，“牌局设置 → 托管节奏”可选 1、3、5 秒。
- 点击“暂停托管”可接管当前牌局；手动选牌或操作也会停止托管。打开设置、复盘或朗读依据会暂停托管。
- 默认开启**“先想后看”**：轮到玩家决策时先隐藏牌面“荐”字角标和“建议……”提示条（改为“先自己想一想”与“揭晓本步建议”按钮），也可通过底栏“先想后看：开/关”一键切换或启用自动托管。一旦点击揭晓或关闭先想后看，具体原因、备选对比及客观测算过程会**直接就地展示在手牌上方**，无需再多点一层弹窗遮挡手牌；若直接自决不揭晓，事后也可点开底栏“刚这手复盘”查看对照。
- 无论就地揭晓还是在“刚这手复盘”中，都会完整展示当前策略给出的推荐、备选、原因与局限，并在定缺后的行牌与响应阶段直接摊开**客观测算明细**（仅按本家手牌、自家明牌与全桌已见公开牌扣减余张）：定缺未清时列出手牌余下定缺牌；清缺后列出各主要候选项的向听数、具体有效进张/可胡牌余张、已见完（余 0 张）的牌及听牌底算番型，并在`V10`推荐偏离纯牌效时如实标注。开局直接列出老师分析与各花色备选；老师弃牌模式保留按需展开的简化两摸对比。
- 打出万、条、筒时会中文报牌。换三张、定缺和清缺门只报结果；其他本家选择朗读该步的简短结论。手动偏离老师建议时，保留当前老师首选及当步已有备选的解释；未展示的手动动作只说明操作事实，不另算分数。内部高级策略来源的手动其他选择、或建议尚未可用时，也只播报操作事实。碰、杠、胡和结算有简短语音与提示音。完整依据可在揭晓后的卡片右上角直接点“朗读”收听。托管等该步语音结束后再按所选节奏继续。声音开关和浏览器的中文音色选择可在牌局设置中调节并保存在本地。

## 策略和解释边界

页面默认启用经独立正式验证的 **`V10` 策略**：开局换三张与定缺沿用“合理老师”，行牌弃牌与常规响应采用公开信息高级策略（Pyodide 本地运行），在普通合法点胡窗口直接兑现本次确定实收；同时保留显式“合理老师”模式作对照（详见 [V10 验收记录](research/INDEPENDENT_BENCHMARK_V10.md) 与 [浏览器接入记录](research/BROWSER_STRATEGY_INTEGRATION.md)）。老师模式使用基于向听、有效进张及最多两摸模型收入的启发式与有限搜索，未经过模型训练；三名电脑对手仍沿用原内置策略。

策略与即时解释只使用本家手牌和公开信息，不读取对手暗牌或真实牌墙顺序。语音在本家行动时计算当步解释，不保存整局决策快照。响应选择可能等待其他人提交，申请碰杠不表示最终获得该面子。进张、收益、风险仍是启发式粗估，不表示精确概率。

按需打开的“两摸牌效比较”仍只看成胡占比，不直接参与排序；老师模型另用本桌三番封顶与自摸加底加权前瞻，两者目标不同，排序可能不同。未见牌既可能在墙中，也可能在对手暗牌中；模型假设从未见牌均匀摸取，不处理对手中途弃牌、碰杠胡或上下文加番。清缺门阶段与牌墙不足两张时不显示两摸对比面板。

## 数据与验证

- 离线强度对照（含已否定未接入的 [V11 实验](research/INDEPENDENT_BENCHMARK_V11.md)）已归档于 [研究归档](research/README.md)。
- 牌局状态和公开动作日志只保存在当前页面内存中，刷新或重新开局会清空；目前没有跨设备存储或牌谱导入导出。
- `src/game/decision.test.ts` 与 `src/game/lookahead.test.ts` 覆盖本家决策、108 张牌守恒、零和结算、暗牌隔离与前瞻边界；`src/strategy/*.test.ts`、`src/components/*.test.tsx`、`src/components/tileBreakdown.test.ts` 与 `src/App.test.tsx` 覆盖 V10 接入、客观测算明细、先想后看开关、手牌新摸分离、刚这手复盘及 UI 展示。静态渲染测试不能替代真实浏览器布局与交互试玩。

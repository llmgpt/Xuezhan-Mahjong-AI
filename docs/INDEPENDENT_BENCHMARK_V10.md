# V10：普通合法点胡直接兑现对照

**候选已实现并完成工程检查，尚无完整新对局结果。** `candidate-advanced-accept-ron-v10`在本家普通弃牌响应、宿主明确允许胡时直接点胡，兑现本次确定实收。它用于检验收胡本身的作用，其余开局、出牌、自摸、抢杠和非胡响应精确沿用V8的full组件；页面默认仍为原老师，V10尚未接入浏览器或进入正式留出。

## 为什么设置这个对照

[V9完整开发组](INDEPENDENT_BENCHMARK_V9.md)没有证明相对V8的增量：总体每局只多0.016667，区间跨零，组合开局和外部阵容仍不稳定。全部186个首分歧中，V9先收胡的115次配对终分总差+43，其他71次−27。先用简单对照区分直接收胡和有偏续局模型的影响，比在这批结果上继续挑粒子阈值更有诊断价值。这些配对路径关联没有证明直接胡总是最优，也不代替新完整对局。

## 决策和解释的边界

- 只拦截`respond/discard`且合法选择包含`hu`的节点，杠后炮和海底等仍由当前V1上下文计入实收；不是抢杠或自摸策略改动。
- 从本家手牌和公开信息重建当前V1实收；这是本次胡的单家付款，不重复加入此前积分，也不乘活跃人数。胡后本家退出后续收付。
- 不抽粒子、不续局、不估计拒胡后的价值。原因明确显示实际确定金额、直接兑现的依据以及可能放弃更大未来收益的局限；不能称作模型证明的最优动作。
- 非目标节点使用V8同一老师开局与`ready-income` worker，保持其返回和正常收尾。实际执行的Python源码缓存合同沿用已修复的缺省启动路径。

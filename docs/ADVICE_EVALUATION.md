# 建议效果评估（初步）

> 2026-10-11，基于当前 V1 规则与启发式策略。以下是内部模拟对照，不是建议已达到真人教学水平的证明。

## 方法

运行 `npm run evaluate:advice`：默认对固定种子 10000～10099，每个种子各完成四局；可用环境变量 `EVAL_START`、`EVAL_COUNT` 改变范围。四组使用相同的初始牌墙与三名电脑对手；本家换三张、定缺、碰杠胡等非出牌决策都沿用当前托管策略，只替换本家出牌：

| 策略     | 本家出牌选择                                           |
| -------- | ------------------------------------------------------ |
| 当前建议 | 向听粗估 → 有效进张 → 收益倾向 → 公开牌风险 → 固定顺序 |
| 简化牌效 | 向听粗估 → 有效进张 → 固定顺序                         |
| 固定首张 | 打出合法牌列表中的第一张                               |
| 随机合法 | 使用独立固定种子的伪随机数，从合法牌中选一张           |

同一种子的四局会因本家选择不同而走向不同牌局。主要观察本家终局净分，胡牌占比仅作辅助：血战到底允许多人先后胡牌，单看胡牌占比容易误读。

## 结果

| 本家策略 | 100 局平均净分 | 本家胡牌局数 |
| -------- | -------------: | -----------: |
| 当前建议 |          +0.41 |           74 |
| 简化牌效 |          +0.60 |           77 |
| 固定首张 |          -2.75 |           20 |
| 随机合法 |          -4.19 |            5 |

按同一种子的终局净分配对，当前建议平均比固定首张高 3.16 分，比随机合法高 4.60 分；这说明牌效排序明显优于这两种很弱的基线。与简化牌效相比，当前建议平均低 0.19 分，配对差值的标准误约 0.17 分。这组样本**没有证据**表明目前的收益倾向和公开牌风险次级排序带来稳定增益，也不足以断言它们有害。

## 还不能证明什么

- 这个对照只隔离了**出牌排序**。换三张、定缺、碰杠胡建议与解释文案尚未做效果对照。
- 固定首张和随机合法出牌是弱基线；三名电脑的碰杠响应策略也较简单。领先弱基线不等于达到有经验玩家的水平。
- 当前向听、进张、收益和风险都基于同一套 V1 规则与粗估；模拟器的规则或估算若有偏差，结果也会受影响。公开牌风险不是经实战校准的放铳概率。
- 样本只有 100 个连续种子，且本家固定为 0 号庄家；还需跨种子、座位、对手策略和地区规则复核。

下一步应先用真实牌例核对规则和关键选择，再做更强基线与跨座位的留出种子评估，记录净分、胡牌时机、杠钱和点炮代价，并检查建议依据是否准确。只有能指出现有启发式策略的具体缺口，才评估搜索、模型或外部 AI 是否能补上；生成更流畅的解释本身不代表建议更有效。

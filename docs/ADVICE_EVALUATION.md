# 建议效果评估

> 更新于 2026-10-14，基于 V1 规则与启发式策略。第一版老师已通过预定的 6400 局内部强度对照，完整证据见[正式报告](TEACHER_REPORT.md)。下文保留旧出牌策略的历史评估和开发过程；两摸前瞻的两组旧留出种子尚未复跑。内部对照不证明真人教学效果。

## 方法

下文历史结果使用原评估器：种子 10000～10099、本家 0 号庄家座位、原电脑（现在命名 `greedy`）对手。五组使用相同的初始牌墙与三名电脑策略；本家换三张、定缺、碰杠胡等非出牌决策沿用当时托管，只替换本家出牌：

| 策略     | 本家出牌选择                                           |
| -------- | ------------------------------------------------------ |
| 当前建议 | 向听粗估 → 有效进张 → 收益倾向 → 公开牌风险 → 固定顺序 |
| 简化牌效 | 向听粗估 → 有效进张 → 固定顺序                         |
| 实验前瞻 | 同向听前三张候选的简化两摸模型，详见下节               |
| 固定首张 | 打出合法牌列表中的第一张                               |
| 随机合法 | 使用独立固定种子的伪随机数，从合法牌中选一张           |

同一种子的五局会因本家选择不同而走向不同牌局。主要观察本家终局净分，胡牌占比仅作辅助：血战到底允许多人先后胡牌，单看胡牌占比容易误读。下表只列四种基础策略；实验前瞻单独列于后文。

2026-10-14 评估脚本已改为独立全座位循环，默认仍选五种基础策略，但对手默认包含 `greedy,patient` 两组；复现历史结果须显式指定 `EVAL_OPPONENTS=greedy`。环境变量 `EVAL_START`、`EVAL_COUNT`、`EVAL_SEATS`、`EVAL_POLICIES` 选择种子、座位和策略，`EVAL_OPPONENTS` 选择对手。`EVAL_OUTPUT` 指定 JSONL 文件后会记录规则、配置、源码 SHA256 并逐种子保存；相同配置可续跑，规则或源码改变则拒绝混用。正式老师验收另按[预定协议](TEACHER_ACCEPTANCE.md)执行。

## 结果

| 本家策略 | 100 局平均净分 | 本家胡牌局数 |
| -------- | -------------: | -----------: |
| 当前建议 |          +0.41 |           74 |
| 简化牌效 |          +0.60 |           77 |
| 固定首张 |          -2.75 |           20 |
| 随机合法 |          -4.19 |            5 |

按同一种子的终局净分配对，当前建议平均比固定首张高 3.16 分，比随机合法高 4.60 分；这说明牌效排序明显优于这两种很弱的基线。与简化牌效相比，当前建议平均低 0.19 分，配对差值的标准误约 0.17 分。这组样本**没有证据**表明目前的收益倾向和公开牌风险次级排序带来稳定增益，也不足以断言它们有害。

解释修正前后在这 100 个固定种子上的汇总完全相同。这只说明这组牌局没有观察到变化，不能据此推断所有局面中的策略表现不变。

## 跨座位留出种子对照

运行以下命令，使用新的一组种子 40000～40099，让被比较的策略分别控制 0～3 号座位；每个“种子 × 座位”分别跑当前建议与简化牌效，共 800 局。两种策略在配对局中拥有相同的初始牌墙、座位和三名电脑策略。0 号仍是庄家，评估没有轮换庄家，也没有替换电脑响应策略。

```powershell
$env:EVAL_START = '40000'
$env:EVAL_COUNT = '100'
$env:EVAL_SEATS = '0,1,2,3'
$env:EVAL_POLICIES = 'advice,efficiency'
$env:EVAL_OPPONENTS = 'greedy'
npm run evaluate:advice
```

| 被控座位   | 当前建议平均净分 | 简化牌效平均净分 | 建议减简化牌效，配对标准误 |
| ---------- | ---------------: | ---------------: | -------------------------: |
| 0          |            +0.79 |            +0.79 |                +0.00，0.14 |
| 1          |            -0.53 |            -0.34 |                -0.19，0.14 |
| 2          |            -0.02 |            -0.20 |                +0.18，0.33 |
| 3          |            -0.25 |            -0.02 |                -0.23，0.27 |
| 四座位均值 |          约 0.00 |            +0.06 |                -0.06，0.11 |

总差值先在每个种子内对四座位求均值，再以 100 个种子估计标准误，避免把同一初始牌墙下的四个座位视为独立样本。各座位差值方向不一致，总体差值小于抽样波动；这次更宽的对照依然没有显示当前次级排序优于简化牌效。两种策略只在出牌选择上不同；简化牌效在自己的 400 局轨迹中，有 246 次出牌与同一时刻的当前建议不同。分数接近不等于它们从未作出不同决定。

## 解释正确性的固定牌例

规则明确的牌例先要求建议**不说错事实**；这与净分是否更高分开验证。`src/game/advice.test.ts` 中可复现的例子包括：

| 牌例                                                | 必须满足的解释                               |
| --------------------------------------------------- | -------------------------------------------- |
| `w1223779 d2346778`，定缺万                         | 只推荐合法缺门牌，并说明须先清缺门           |
| `w11123429 s345678`，定缺筒，比较二万/九万          | 打九万有更多有效进张，应明确列出差异         |
| `s11223344556`，已碰九万，定缺筒                    | 不得声称“有清一色潜力”；异色明碰不能拆回     |
| `s11223344556` 已碰九条；`s11223344` 已碰七条、九条 | 仍可标注清一色潜力，不能因暗手少于八张而漏报 |
| `w1111223356 s4478`，定缺筒，打八条后有五对         | 四张一万按本桌规则算两对，应标注七对潜力     |

这些测试只约束规则事实与文案的局部一致性，牌例是人工构造的边界情形，尚非独立高手标注的“最佳出牌”数据集。后续需要收集真实对局中的争议局面，独立核对推荐是否合理、解释是否忠实于实际排序依据，并保留可能并列的选择。

另用[外部教学牌例](ADVICE_CASE_AUDIT.md)核对了一个完整 14 张手牌的出牌排序和两个 13 张手牌的全部等待牌，均与公开说明相符；还记录了一个“快做七对或慢做清一色”的叙述性分歧，并为清一色备选补充尚需舍牌的事实说明，不改变推荐排序。外部材料缺少完整比赛牌谱和公开牌面，不能据此认定当前建议已被专家验证。

## 两摸前瞻实验

当前建议详情可按需比较两张候选牌：从本家手牌与公开牌扣除已见张数，枚举下次摸牌；若不能直接胡，则从合法弃牌中选一个让第二次摸牌成胡机会最多的延续。它不使用真实牌墙或对手暗牌，不模拟两次本家摸牌之间的对手行动、点炮及番型收益，因此只是教学用的简化牌效比较，**不参与当前建议或托管排序**。

离线评估另设实验性“前瞻”策略：在简化牌效排序的同向听前三张候选内，以两摸模型成胡占比重排，其他行动仍按现有托管策略。分别在此前未使用的种子 20000～20099、30000～30099 对照；本家仍固定为 0 号庄家，对手策略未变。

| 种子组       | 当前建议平均净分 | 简化牌效 | 实验前瞻 | 前瞻减简化牌效，配对标准误 |
| ------------ | ---------------: | -------: | -------: | -------------------------: |
| 20000～20099 |            +0.05 |    -0.26 |    -0.05 |             +0.21，约 0.17 |
| 30000～30099 |            -0.39 |    -0.41 |    -0.28 |             +0.13，约 0.22 |

两组方向相同，但差值小于抽样波动；当前建议与实验前瞻也没有稳定可辨的差距。不能据此宣称前瞻提高实战表现，更不能把两摸模型百分比当作真实胡牌率。未来若要让前瞻参与推荐，需先校准对手行动与未见牌分布，再跨座位、不同对手和更多留出种子复核。

## 上述历史对照还不能证明什么

- 这个对照只隔离了**出牌排序**。换三张、定缺、碰杠胡建议与解释文案尚未做效果对照。
- 固定首张和随机合法出牌是弱基线；三名电脑的碰杠响应策略也较简单。领先弱基线不等于达到有经验玩家的水平。
- 当前向听、进张、收益和风险都基于同一套 V1 规则与粗估；模拟器的规则或估算若有偏差，结果也会受影响。公开牌风险不是经实战校准的放铳概率。
- 初始对照只有 100 个连续种子，跨座位留出对照也只有 100 个种子，前瞻实验仅有两组各 100 个种子。本家虽在跨座位对照中轮换，庄家始终固定为 0 号；还需用不同对手策略、地区规则和独立真实牌例复核。

下一步先形成合理、可解释的候选规则，通过内部对照快速筛选，再在真实对局中找问题并修正；不以获得完整的高手标注数据集为开发前置条件。更换电脑策略、增加留出种子时，记录净分、胡牌时机、杠钱和点炮代价，并检查建议依据是否准确。只有能指出现有启发式策略的具体缺口，才评估搜索、模型或外部 AI 是否能补上；生成更流畅的解释本身不代表建议更有效。

## 结构保留换三张候选

`src/game/openingAdvice.ts` 实现了只读取本家手牌的确定性候选。它枚举所有合法同门三张组合，对同张联系计 4 分、相邻联系计 2 分、隔一张联系计 1 分，选择换出后联系损失最小的组合；并列时优先手牌张数较少的花色，再按牌值固定顺序选择。这些权重是人为设定的启发式，尚未用牌局数据拟合。它不预测收到的三张牌，也不评价向对手送牌的收益。

三项代表性测试覆盖保留连续搭子、同门超过三张时的组合选择、输入顺序与手牌不变性。离线评估的 `opening-structure` 只替换本家换三张，后续出牌、定缺和碰杠胡仍用旧建议；对手策略也保持相同，输出新增 `changedExchanges` 统计。该换牌模块现已参与完整老师和页面托管，但正式对照未把换牌与定缺各自的贡献拆开。

2026-10-13 曾启动种子 50000～50099、四座位、`advice,efficiency,opening-structure` 对照，但执行被中断，没有保留可用汇总。不能把该次启动记作策略有效性证据。此后评估器已补逐种子进度、结果保存和续跑校验。

## 可借鉴的外部 benchmark

[北大团队的麻将 AI 赛事论文（IJCAI 2024）](https://www.ijcai.org/proceedings/2024/1020.pdf)介绍了 Botzone 的国标麻将评估：用 24 局座位全排列构成一个 duplicate 组，各座位拿到相同牌，以减小牌运和座次影响。比赛采用 MCR 国标规则，规则、番型和胡牌门槛与本项目的四川血战 V1 不同，因此不能直接移用其榜单或最佳动作标签。

本项目借用配对和跨座位比较的思路。当前评估只保证配对局的**初始牌墙**相同，策略改变后摸牌和响应轨迹会分叉；三名对手策略固定、庄家固定为 0 号，也不是赛事的完整 duplicate 实现。它适合作为快速迭代规则的内部 benchmark，后续补不同对手和真实局面验证。

## 第一版合理老师与开发评估

`teacher-candidate` 保持只读 `PlayerView`，采用结构保留换三张；定缺比较清门张数和剩余两门成牌距离。出牌先保留最小向听，在近听（不超过一向听）的牌效前三候选中，用均匀未知牌模型比较最多两次本家摸牌的成牌与自摸收入；按本桌三番封顶、未胡对手各付牌型分加 1 计值。牌墙已空时不预测再摸牌，比较本桌理论等待的查叫最高牌型分。碰杠胡沿用经过牌例验证的动作建议，并以老师出牌作为“不杠”的基准。

这是有限模型下的规则策略，未模拟中间对手行动、点炮或海底/杠上等上下文加番；已接入本地页面。清一色收益与更宽进张的代表性取舍已写入测试，外部六搭牌例保留估算并列提示；测试约束规则事实和解释一致，不充当强度证据。策略标识保留 `teacher-candidate`，正式结果列在下一节。

开发对照预定种子 60000～60039，四座位、`greedy,patient` 两类对手，比较 `advice,efficiency,teacher-candidate,teacher-legacy-discard`，共 1280 局。直接老师减各基线的差值及 95% 区间另列，不能把两条原 advice 对照的标准误相减。完整实现和正式通过条件见[老师验收协议](TEACHER_ACCEPTANCE.md)。

开发对照已经完整跑完（40 个种子为聚类样本）：

| 对照（老师减基线）                    | 平均净分差 | 95% 正态近似配对区间 |
| ------------------------------------- | ---------: | -------------------: |
| 当前建议 `advice`                     |     +0.684 |       [0.108, 1.261] |
| 简化牌效 `efficiency`                 |     +0.769 |       [0.168, 1.370] |
| 出牌模块回退 `teacher-legacy-discard` |     -0.034 |      [-0.265, 0.196] |

整体开发结果有增益，但主要来自开局；出牌模块额外收益未分出高下。对 patient 对手，老师相对 advice 的开发差为 +0.344，区间仍跨零。这些开发结果不用于宣称通过正式验收。

## 正式留出结果（2026-10-14）

按事先冻结的[验收协议](TEACHER_ACCEPTANCE.md)，种子 70000～70199、四座位、两类对手和四策略共 6400 局全部完成。以 200 个种子聚类计算成对差，而非把 1600 局当作独立样本；四个预定分片全部纳入，运行期间未改策略或依据途中成绩选择分片。

| 对照（老师减基线）                    | 平均净分差 | 95% 正态近似配对区间 |
| ------------------------------------- | ---------: | -------------------: |
| 原建议 `advice`                       |     +0.918 |       [0.685, 1.151] |
| 简化牌效 `efficiency`                 |     +0.901 |       [0.673, 1.128] |
| 出牌模块回退 `teacher-legacy-discard` |     +0.016 |      [-0.096, 0.129] |

两类对手下，相对原建议与简化牌效的差值分别也为正，区间下界均大于零。出牌模块回退对照满足预定 -0.25 分/局的阶段容差，但区间跨零，**尚未证明新出牌模块单独提高净分**。回退旧出牌仍保留新换牌和定缺时，相对原建议增加 0.902 分/局；因此本次主要收益来自开局组合，不能进一步拆成换牌或定缺的独立收益。

原始配对完整性、源码及原始文件 SHA256、统计重算均经过独立复核。预定强度条件已通过，`npm run check` 的 123 项测试通过；本次浏览器整局试玩因本地地址访问许可被拒绝尚待完成，因此总体试玩验收仍待用户。分对手、分座位结果、复现命令及原始记录见[正式报告](TEACHER_REPORT.md)。结果只支持本桌 V1 和这两类电脑环境中的策略收益，不证明每手最优或玩家学习效果。

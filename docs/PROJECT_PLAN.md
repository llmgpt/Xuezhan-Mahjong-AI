# 血战麻将学习项目：产品计划

## 已确定的方向

- **形式与仓库**：浏览器单页游戏，公开仓库为 [llmgpt/Xuezhan-Mahjong-AI](https://github.com/llmgpt/Xuezhan-Mahjong-AI)。
- **玩法基准**：常见四川血战到底；V1 具体取舍见 [第一版规则表](RULES_V1.md)。
- **核心学习目的（2026-11-14 明确）**：帮助玩家解决“看教学视频时节奏太快、讲解跳过中间计算步骤而跟不上”的痛点，通过自己打牌与可控对比来学会数进张和比较打法。
- **当前优先级**：优先打磨教学互动与解释透明度；策略强度只要“不明显乱打、能讲清理由”即可，暂停追逐更高对抗分数（2026 年 10 月 V1–V11 强度研究已归档于 [研究归档](research/README.md)）。

## 当前已建成能力

1. **完整可玩 V1 牌桌**：换三张、定缺、摸打、碰、直杠/暗杠/补杠、自摸/点炮/抢杠、多人胡与血战继续、番型及流局查叫/花猪结算；支持固定整数种子复现。
2. **实体风格牌面与语音**：本地 SVG 按常见实体麻将重画 27 张万/条/筒；支持自动托管（1/3/5 秒节奏）与浏览器中文语音报牌。
3. **先想后看与就地摊开算账教学流**：默认隐藏牌面“荐”标记与建议条，支持先想再点“揭晓本步建议”、底栏一键切换“先想后看：开/关”以及自决后查看“刚这手复盘”；推荐揭示后，理由、备选与客观测算直接就地紧凑展示在手牌上方（不再加“查看依据”二次点击或遮挡牌桌弹窗），无论是默认 `V10` 还是“合理老师”模式，均直接对照手牌展示定缺清理、各候选向听数、扣减桌牌后的有效进张/听牌余张与底算番型。

## 下一步教学迭代方向

1. **整局关键手时间线回看**：当前仅保留最近一手`刚这手复盘`；后续可支持整局回看高分差或分歧更大的关键几手，不必事后翻动作日志。
2. **策略对照入口评估**：结合教学试玩反馈，决定是否在牌局设置中提供“合理老师”与 `V10` 的轻量切换说明，服务“先懂过程再看实战取舍”。
3. **地区规则可选项**：如自摸加底/加番、天地胡等差异，先在 [第一版规则表](RULES_V1.md) 明确边界再配置。

## 规则目标与协作边界

- 开局、行牌、胡牌、计分与流局结算的第一版固定选择见 [第一版规则表](RULES_V1.md)；其余地区差异保留为独立可配置方向。
- 玩家建议与自动托管严格只读本家手牌和公开信息（[自动托管与实时建议](AUTOPLAY.md)）。
- 推送或合并公开 GitHub 仓库、公开部署网页均需明确授权；平时以聚焦的本地分支与提交推进。
- 模块边界见 [ARCHITECTURE.md](../ARCHITECTURE.md)；开发与文档守卫规范见 [ENGINEERING.md](ENGINEERING.md)。

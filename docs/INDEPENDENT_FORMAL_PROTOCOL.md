# 正式评测入口准备

> 更新于 2026-10-19。已实现科学协议/种子登记、单种子原始动作重放及运行时文件采集三个基础模块。当前格式、lint、类型、38 文件 335 项 TypeScript 测试及构建均通过，测试限制为两个 worker；Python 源未改，原 95 项结果保留。正式执行 wrapper 尚未实现；没有创建真实正式种子预约，没有选定正式候选、门槛或新留出。开发 CLI 仍拒绝 `formal` 模式。

[formalProtocol.ts](../scripts/formalProtocol.ts) 明确区分外层 `purpose=formal` 与复用引擎的 `innerEngineMode=development`。科学配置必须先指定样本数、完整对手映射、源码指纹、V1 规则、相关运行时、全部通过条件、统计与失败恢复合同；这一步不含种子。四座位、共同/组合两开局及至少两个不同作者的外部来源是必要条件，初级与高级 ebony 阵容只算同一来源。主提升条件必须相对当前老师、阈值非负，且覆盖两外部来源；统计方法不能在见到结果后更换。

统计固定为 seed 内所选网格等权合成，再按 seed 估计均值和 SE。全部通过条件共同使用预先指定、通过 Bonferroni 双侧正态近似校正检查的临界值；每个条件的区间下界必须严格超过其预定阈值。代码要求至少 30 个 seed 只是近似法的最低入口限制，不能据此保证样本量充分或分布近似可靠。实际样本量和实际差阈值仍须根据开发方差与计算成本在新 seed 放出前固定。

`summarizeFormalStatistics` 只返回统计条件是否满足，保留所有原面板、比较和收入；它不能单独代表原始日志、执行或高手水平通过。真实执行还必须验证源码/构建及运行时字节、完整网格、无终止性错误和逐动作重放。当前测试用合成零和统计记录验证 seed 聚类和阈值，不把这些合成记录当作真实完整牌局。

`reserveFormalSeeds` 要求已初始化的历史账本、精确样本数和唯一种子。独占锁内先核历史范围、已有预约及计划哈希，再把整组预约 fsync 后原子替换写入；重复完全相同的恢复不重复写入。旧 seed、别的计划已消费的 seed、改变原计划/种子顺序、损坏或被占用的账本均拒绝。这个模块不会自己推断全部历史；真实历史清单的汇总、导入来源核对及运行 manifest 绑定仍是未实现 wrapper 的责任。测试账本只是临时合成文件，未预约项目真实留出。

[formalAudit.ts](../scripts/formalAudit.ts) 只接收单 seed 的完整 attempt。逐行审核成绩 manifest/envelope 与成功 trace 的精确笛卡尔积，拒绝失败、额外/重复/缺失日志、未知字段和截断。按既存动作调用可信引擎重放，不再次询问任何候选；核对每步完整公开视图、座位、阶段、step、合法动作、共同开局及最终胡牌/番型/积分收入。只有 `DEFAULT_RULES` 真正在引擎执行，非默认标签不能冒充规则变体。文件审计前后再核 SHA256，报告仅输出原始哈希、公开终局与计数。

首次模块缺失 RED 后完成实现；另加动作额外载荷回归，观察到错误接纳的 RED，再补严格动作 schema 后通过。模块已实际重放 Fanfou 烟测的 96 局、5,516 个决定、8,756 个守恒状态，全部一致，材料见[组合参考报告](INDEPENDENT_REFERENCE_FANFOU.md)。这属于对已用开发材料的审计，不是新的正式实验。

[formalRuntime.ts](../scripts/formalRuntime.ts) 仅查询所需策略的 Python 模块：原参考不导入 NumPy，BA 在受评或对手中出现才要求固定 `2.1.3`。采集实际 Node/Python 可执行文件、可发现的解释器共享库、探针加载的模块文件、NumPy RECORD 和非缓存自有文件 SHA256，并记录解释器标记及六项相关环境值；不修改环境或导出整份环境。额外元数据、缺标记、依赖缺失和越界文件均拒绝。它不是完整操作系统或未加载依赖的冻结。

六项模块测试已 RED→GREEN；真实探针先发现 Python 共享库遗漏的失败，补齐后旧参考采集 77 个模块/库文件、无 NumPy，新组合 214 个模块/库文件和 830 个 NumPy 非缓存自有文件。另复制 101 项源码，把只读入口打包为独立 Node `.mjs` 后实际执行，运行时记录与活动源码探针逐字段一致；22 个构建输入和产物 SHA 已保存。没有执行牌局或生成/预约新留出。[版本化证据](benchmarks/formal-runtime-preparation.json)仅保存摘要及本地原始文件哈希，不公开可执行文件或安装目录的绝对路径。

剩余执行入口需要：只从冻结快照/构建产物运行；把已有 runtime 采集接到运行前后校验；初始化完整已用 seed 历史；原子预约与 run manifest 绑定；每 seed 新 attempt、严格前缀恢复和成绩/轨迹双哈希收据；分片精确无重叠并集；全部原始网格完成后才应用预定门槛。策略/依赖/非法动作/worker/timeout/源漂移不得换 seed 或修完后续称同一次正式检验。设计细节在忽略的 `local/strength-goal-20261018/formal-runner-design/`，未完成的部分不能按已有功能使用。

# 血战麻将学习项目

目标是做一个可以在浏览器里玩的四川血战到底麻将项目，重点是帮助玩家提升技术。

## 想做的功能

- 自己打牌时获得出牌建议，并看到建议依据。
- 让电脑托管本家操作，边看牌局边查看当前建议与依据。

规则目标见 [第一版规则表](docs/RULES_V1.md)。各地与平台差异在规则表中列为本版选择和可配置方向。

## 当前状态

现有 TypeScript、React、Vite 的**本地可试玩 V1**：玩家与三名电脑对手可以完成一局。页面默认随机开局，也支持固定种子复现；包含换三张、定缺、摸打、碰、三种杠、自摸与点炮、多人胡、抢杠胡、血战结束和计分。出牌时展示推荐与备选、牌效率粗估、收益倾向、风险提示及局限；建议详情可按需比较候选牌的简化两摸前瞻。支持玩家自动托管、轻量操作声效与中文报牌。对局结束显示积分和胡牌记录。电脑与建议使用启发式策略，未经过模型训练；目前没有账号或在线多人模式。公开仓库是 [llmgpt/Xuezhan-Mahjong-AI](https://github.com/llmgpt/Xuezhan-Mahjong-AI)；具体规则见[规则表](docs/RULES_V1.md)，模块边界见 [ARCHITECTURE.md](ARCHITECTURE.md)。

## 本地运行与检查

牌桌采用适应窗口高度的一屏布局，万字、竹条和筒圈为本地 SVG 牌面；手牌按花色与点数排列，弃牌、碰杠和建议也使用图案牌面。手牌、当前操作和推荐原因保持在牌桌底部，窄屏与小高度横屏使用紧凑布局。点击“查看依据”在弹窗中查看比较与局限；设置、玩法提示和对局记录也使用弹窗，长内容在弹窗内滚动，关闭后继续打牌。估算相同的候选会明确标为并列。换牌时点选三张，出牌时点击亮起的手牌；顶部“随机开局”与结算后“再来一局”会生成新种子，牌局设置中可查看本局种子并按指定种子重新开局。

可碰、直杠、暗杠、补杠或胡牌时，页面也会给出动作建议，推荐按钮标“荐”；建议过或先出牌时同样说明原因。“查看依据”列出全部合法动作的取舍，比较碰后的最佳弃牌、杠前后的牌型效率、七对资格及本桌杠钱，并说明补杠抢杠风险。动作建议采用保守的启发式策略，优先当前可胡的牌；补牌只按未知牌处理。当前页面默认使用V10：沿用“合理老师”的换牌与定缺、高级弃牌及响应，并在普通合法点胡时直接兑现当前确定收益。V10已在400个未用正式种子、19200局对照中通过三项预定条件，相对原老师总体平均每局增加0.508分；这证明的是预定对照中的提升，不代表高手水平。显式老师模式仍保留作对照，完整证据见[V10记录](docs/INDEPENDENT_BENCHMARK_V10.md)。

牌桌底部点击“自动托管”代替自己操作，默认在每次本家决策前停留 3 秒，牌局设置可选 1、3、5 秒；三名电脑对手照常行牌。暂停或手动操作可接管，打开设置或建议依据也会暂停托管。牌局状态与最近的公开动作日志只存在当前页面内存，刷新或重新开局会清空；不保存本局决策复盘。操作和策略边界见 [自动托管与实时建议](docs/AUTOPLAY.md)。

出牌时会用中文报出点数和花色（如“三万”“九条”）；换三张、定缺和清缺门只报结果，其他本家选择朗读当步的简短结论。碰、杠、胡及结算也有简短语音，选牌与关键操作有轻量提示音。若玩家未按建议行动，语音会区分实际选择与系统建议。完整依据可在当步“查看依据”弹窗主动朗读。托管会等本步朗读结束，再按所选节奏继续。牌局设置中可关闭“声效与中文报牌”，并可选择浏览器提供的中文声音、点击试听；声音选择与开关会保存在当前浏览器。语速已调回正常，实际音色仍取决于浏览器和系统提供的语音。

需要 Node.js 22。干净检出后执行：

```bash
npm ci
npm run dev
```

打开 Vite 打印的本地地址，按页面提示换牌、定缺、打牌；每次随机开局会更新本局种子，在牌局设置中输入同一个整数种子和重复相同选择，可以重现发牌及电脑决策。使用 `npm run check` 一次运行格式、ESLint、TypeScript、固定牌例测试与生产构建；单独命令为 `npm run format:check`、`npm run lint`、`npm run typecheck`、`npm test`、`npm run build`。本地格式化可运行 `npm run format`。`npm run evaluate:advice` 单独运行 100 个固定种子的出牌策略对照，不纳入日常检查；详情见[建议效果评估](docs/ADVICE_EVALUATION.md)。

本地开发环境已准备 `git-workflow-and-versioning`、`test-driven-development` 和 Serena MCP。它们用于辅助开发，不是游戏运行依赖；其他贡献者无需安装这些工具即可参与项目。
